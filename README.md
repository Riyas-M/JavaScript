
## JS Fundamentals

### Core Fundamentals:

- #### Variables (var, let, const):
    Understanding the different ways to declare variables and their respective scoping rules (global, function, block).

- #### Data Types:
    Familiarity with primitive types (string, number, boolean, null, undefined, symbol, BigInt) and object types (objects, arrays, functions).

- #### Operators:
    Knowledge of arithmetic, assignment, comparison, logical, and other operators.

- #### Functions:
    Defining and invoking functions, understanding parameters and return values, and grasping concepts like function scope and arrow functions.

- #### Objects:
    Working with object literals, properties, methods, and the this keyword.

- #### Arrays:
    Utilizing array methods for manipulation and iteration (e.g., map, filter, reduce).

- #### Control Flow:
    Implementing conditional statements (if/else, switch) and loops (for, while, do/while).


### Advanced Concepts:

- #### Scope & Closures: 
    Deep understanding of how variable access is determined and how closures create persistent access to outer function scope.

- #### Hoisting: 
    Knowing how variable and function declarations are "hoisted" to the top of their scope.

- #### Asynchronous JavaScript:
    - ##### Callbacks: Using functions as arguments to handle asynchronous operations.

   - ##### Promises: A more structured way to manage asynchronous code, addressing "callback hell."

   - ##### Async/Await: Syntactic sugar built on Promises, simplifying asynchronous code readability and error handling.

- #### Prototypes & Inheritance:
    Understanding JavaScript's prototypal inheritance model.


- #### Event Loop: 
    Comprehending how JavaScript handles asynchronous tasks and the execution order of code.

- #### Destructuring & Spread/Rest Operators:       
    Efficiently extracting values from arrays/objects and handling function arguments.

- #### Higher-Order Functions:
    Functions that take other functions as arguments or return functions.



### Modern JavaScript (ES6+):

- #### Template Literals: Enhanced String Interpolation
    Template literals make working with strings more powerful and readable. They allow you to embed expressions and create multi-line strings easily using backticks (`).

- #### Destructuring Assignment: Extracting Values Easily
    Destructuring allows you to unpack values from arrays or properties from objects into distinct variables. It simplifies extracting data from complex structures.

- #### Default Parameters: Simplified Function Arguments
    Default parameters allow you to set default values for function parameters, which is helpful when certain arguments are not provided.

- #### Rest and Spread Operators: Versatile Syntax
    The rest (...) and spread (...) operators provide more flexibility when working with arrays, objects, and function arguments.

- #### Arrow Functions: Concise Syntax for Functions
    Arrow functions - an es6 feature is used to relieve code of redundancy and make it more concise, and arrow functions are one way to write better code. They are most important for callbacks and for one-liners.

- #### Classes: Cleaner Object-Oriented Programming
    ES6 introduced a more straightforward syntax for creating classes and working with object-oriented concepts like inheritance. Classes in JavaScript are syntactical sugar over the existing prototype-based inheritance.

- #### Modules: Native Import and Export
    Modules allow you to split your code into reusable pieces, making it easier to maintain and scale. Using export and import, you can control what parts of your code are exposed to other files.

- #### Promises: Simplified Asynchronous Programming
    Promises provide a cleaner way to handle asynchronous operations, avoiding callback hell. A promise represents a value that may be available now, or in the future, or never.

- #### Enhanced Object Literals: Concise Syntax
    ES6 enhanced object literals adding, Shorthand properties, and methods as well as Computed property names.

- #### Octal and Binary Literals in ES6:
    ES5 provided numeric literals in octal (prefix 0), decimal (no prefix), and hexadecimal (0x). ES6 added support for binary literals and changed how it represents octal literals.
